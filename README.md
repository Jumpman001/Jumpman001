## Hi, I'm Komil 👋

Python developer and AI integrator. I build automation tools for real industrial workflows,
mostly for a fiberglass (GRP) pipe factory in Tajikistan, where I also work on the production side.

**What I do**
- Telegram bots and Mini Apps for production teams (aiogram 3, FastAPI)
- Data pipelines on PostgreSQL + SQLAlchemy 2, deployed with Docker on Google Cloud Run
- LLM integrations: tender monitoring, document parsing, summaries (Claude, DeepSeek)
- Web scraping of procurement portals (World Bank, ADB, EBRD, local sources)
