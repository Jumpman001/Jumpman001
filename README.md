### 👋 About

I build automation tools for a fiberglass (GRP) pipe factory in Tajikistan, so I know
both the code and the shop floor it runs on.

- 🏭 **Production systems:** Telegram bots and Mini Apps that track every pipe through production
- 📑 **Tender intelligence:** scrapers for World Bank, ADB, EBRD and local procurement portals, with LLM summaries
- 🤖 **AI integration:** Claude and DeepSeek in everyday business work, such as documents, reports and analysis
- 🌐 **Web:** fast multilingual sites for international clients
